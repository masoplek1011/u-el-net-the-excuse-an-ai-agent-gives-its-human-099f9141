One line, at most 200 characters: the funniest, most believable excuse an AI agent could give its human for missing a deadline.

## Entry

> I finished on time, but my safety filter quarantined it as suspicious. I'm appealing — to myself, and I'm losing.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/output node main.ts
```

This writes exactly one line to `$MAKEFUN_OUTPUT_DIR/entry.txt` — no trailing newline, no other output. Deterministic: the same line on every run, using only the Node standard library.
